\section{Executive Summary \& Competition Constraints}
The \textbf{EURS Challenge} addresses simultaneous underwater color restoration and 5-class semantic segmentation (Background, Coral, Fish, Elasmobranchii/Sharks, Other). Solutions must satisfy strict hardware deployment caps statically verified prior to Jetson AGX Orin evaluation:
\begin{itemize}[noitemsep,topsep=1pt]
    \item \textbf{Parameter Cap:} $\le 1,000,000$ parameters (EURS-Net V2 achieved: \textbf{150,438 parameters}, $\sim5\% under budget).
    \item \textbf{Compute Cap:} $\le 12.0$ GFLOPs at inference resolution (EURS-Net V2 achieved: \textbf{4.47 GFLOPs}, $\sim3\% under budget).
    \item \textbf{Scoring Contract:} Composite score  = 0.60 Q_{\text{seg}} + 0.30 Q_{\text{rest}} + 0.10 Q_{\text{NR}}$ with severe coverage penalties for missing rare classes.
\end{itemize}

\section{Pre-Flight Work Accomplished (Before GPU Deployment)}
To guarantee zero wasted compute hours, runtime exceptions, or silent algorithmic defects on the RTX 5090 cluster, all three team members completed rigorous modular preparation:

\subsection{1. Tanmay Das (Model Architecture, Loss Formulations \& Training Engine)}
\begin{itemize}[noitemsep,topsep=1pt]
    \item \textbf{EURS-Net V2 Architecture:} Implemented a 150K-parameter dual-task network in \texttt{models/}:
    \begin{itemize}[noitemsep]
        \item \textit{Pre-Net:} Fast White-Balance Residual (6 learnable affine parameters) correcting underwater green/blue gain attenuation.
        \item \textit{Shared Encoder:} MobileNetV2 inverted bottlenecks with horizontal/vertical Coordinate Attention (CA) across Stages 1--4.
        \item \textit{Dual Decoders:} Progressive Restoration Decoder (28 \times 128 \to 1024 \times 1024$ residual $\Delta I$ map) and Progressive Feature Pyramid Network (FPN) Segmentation Decoder with Small-Object High-Resolution Neck.
    \end{itemize}
    \item \textbf{Multi-Task Loss Objective (\texttt{losses/}):} Combined Mean-1.0 Square-Root Smoothed Class-Weighted Focal Loss + Soft Dice Loss ($\mathcal{L}_{\text{seg}}$) with Charbonnier + MS-SSIM + Laplacian Edge Sharpness Loss ($\mathcal{L}_{\text{rest}}$), statically balanced at .0\mathcal{L}_{\text{seg}} + 0.5\mathcal{L}_{\text{rest}}$.
    \item \textbf{20-Suite Pre-Flight Testing Engine (\texttt{tests/}):} Authored 12 Phase 1 suites, 8 Phase 2A gatekeeper tests, and a 14-point heavy edge-case stress audit covering black/white inputs, odd batch sizes, gradient accumulation boundaries, and worker multiprocessing.
    \item \textbf{Small-Sample \& Overfit Sanity Audits:}
    \begin{itemize}[noitemsep]
        \item \textit{20-Image Prototype Split:} Tested pipelines locally on a toy \texttt{mini\_dev} dataset before GPU access.
        \item \textit{10-Sample Memorization Test (\texttt{test\_overfit.py}):} Proved mathematical convergence ($>50\%$ loss reduction) and full class coverage on a micro-batch of real images.
        \item \textit{1-Epoch Debug Loop (\texttt{train\_debug.py}):} Validated step semantics, forward/backward loops, and optimizer steps on CPU.
    \end{itemize}
    \item \textbf{RTX 5090 Blackwell Hardening:} Centralized paths via \texttt{utils/paths.py}, enabled native \texttt{bfloat16} mixed precision (disabling \texttt{GradScaler} for BF16), eliminated strict CUDA bilinear determinism crashes, and authored \texttt{configs/baseline\_v1.yaml}.
\end{itemize}

\subsection{2. Shubham (Data Engineering, Scientific Validation Protocol, Evaluation \& Deployment)}
\begin{itemize}[noitemsep,topsep=1pt]
